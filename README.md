# nuvio-art

Personal collection-tile art for my Nuvio setup. Served via jsDelivr, pinned by tag
(`https://cdn.jsdelivr.net/gh/jbuschini18/nuvio-art@<tag>/<path>`).

| Folder | What | Source |
|---|---|---|
| `streaming/` (peacock, starz, shudder, discoveryplus) | covers + focus GIFs | made by `tools/make_tiles.py` (logos from Wikimedia Commons, code-generated gradients) |
| `streaming/` (other 8), `discover/`, `genres/cover/` | covers + focus GIFs | mirrored from [rsa16/NuvioMinimalistCollection](https://github.com/rsa16/NuvioMinimalistCollection) |
| `studios/` | cover, focus, title, backdrop | mirrored from [luckynumb3rs/stremio-perfect-setup](https://github.com/luckynumb3rs/stremio-perfect-setup) |
| `decades/`, `runtime/`, `genres/alt/` | plain gradient cards | code-generated by `tools/make_cards.py` (no AI imagery) |
