# nuvio-art

Personal collection-tile art for my Nuvio setup (streaming service folders).

- `streaming/focus/*.gif`: 800x450, 6 s @ 30 fps, looping focus/hover animations (white logo over a code-generated brand-colour gradient; no AI imagery)
- `streaming/cover/*.png`: 1280x720 static covers (white logo on #333333)
- `tools/make_tiles.py`: script that generates them (Python + cairosvg + ffmpeg + gifsicle)

Styled to match the streaming tiles in [rsa16/NuvioMinimalistCollection](https://github.com/rsa16/NuvioMinimalistCollection).
